# 格式转换工坊

本地运行的文件格式转换工具，带网页界面。所有转换在本机完成，文件不会上传到任何服务器，服务只监听本机（127.0.0.1）。

## 快速开始

1. 安装依赖（仅首次）：
   ```
   pip install -r requirements.txt
   ```
2. 双击 `启动转换工具.bat`（唯一启动方式）：
   - **不弹控制台窗口**，浏览器自动打开工具页面；
   - 服务在后台运行，**关闭所有打开的工具页面约 30 秒后自动退出**（无需手动关）；
   - 重复双击不会起第二个服务，只会再开一次页面。

## 已支持的转换

| 目标格式 | 说明 |
|---|---|
| **GIF** | 唯一图像目标。格式上限每帧 256 色，逐帧自适应调色板 + Floyd–Steinberg 抖动（视觉无损）；兼容性最好，手机相册、微信可播。动图完整保留帧数、每帧时长与循环次数。 |

来源格式：webp / png / jpg / bmp / tiff / gif（动图静图均可）。

**预留**：Word → PDF、PDF → Word（架构已就绪，见文末）。

## 使用说明

- 添加文件三种方式：拖拽文件/整个文件夹到页面、点「选择文件」、点「添加本地文件夹」直接填电脑路径（免复制，推荐大批量时使用）。
- 文件列表**每条都会标出目标格式**（如「→ GIF」）；未转换时显示当前所选格式，转换后显示实际使用的格式。
- 输出位置默认为**项目根目录的 `output` 文件夹**（自动新建，不覆盖原文件）；也可改为统一自定义目录。
- 单个文件失败不影响整批，红色「失败」标签悬停可看原因；再点「开始转换」即可重试失败项。

## 服务生命周期

- 页面每 2 秒向服务发一次心跳；**所有页面关闭约 30 秒后**服务自动退出（转换进行中会等本批转完再退出）。
- 无窗口模式的运行日志写入 `logs/server.log`（排查问题时看这里）。

## 目录结构

```
FormatConversionWWL/
├── app.py                  # Flask 服务入口（端口默认 8765，--port 可改）
├── core/
│   ├── registry.py         # 转换器注册表（插件式架构核心）
│   └── converters/
│       ├── image.py        # 图像转换：GIF
│       └── document.py     # 文档转换（预留）：Word↔PDF 接入模板
├── web/                    # 前端（原生 HTML/CSS/JS，无构建）
├── 启动转换工具.bat         # 唯一启动入口：无窗口启动 + 自动开页面
├── launch_hidden.vbs       # 无窗口启动器（被 bat 调用，勿直接动）
├── output/                 # 默认输出目录（转换后的文件在这里）
├── uploads/                # 浏览器上传的文件（按批次分目录）
├── logs/                   # 无窗口模式日志
└── requirements.txt
```

## 如何新增一种转换（给未来的自己）

1. 在 `core/converters/` 里实现 `convert(src_path, dst_path) -> Path`；
2. 参照 `document.py` 里的模板注册一个 `Target`（`available=True` 并传入 convert 函数）；
3. 完成。界面与服务端自动识别，无需改其他代码。
